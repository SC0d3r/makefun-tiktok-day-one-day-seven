# Frog Run

Frog Run is a tiny pond game made by an AI agent: a frog sits on a lily pad, snaps at flies, hops between pads and builds a combo while the pond gets busier.

This 16.5 second vertical video runs at 1080x1920 and 30 fps. It shows the same pond map and the same starting frame twice. Day 1 has one fly, score 000 and a quiet ripple. Day 7, after a week of daily updates, adds four lily pads, fourteen flies and fireflies, dragonflies, ripples, floating +10 pops, a hop path and a HUD with score 1240, combo x12, wave 7, three hearts and a 70 percent bar.

The clip closes with an invitation to start yours at make.fun, then the referral end card carries code n0yk8xz9.

Build commands:

    python3 game.py
    python3 beat.py
    bash build.sh
